# Портфолио — Сергей Карпушкин (UX/UI)

Персональный сайт-портфолио UX/UI-дизайнера с мини-CMS: статичный сайт, данные которого берутся из `content.json`, а редактировать их можно через встроенную админку. Без фреймворков и сборки — только HTML/CSS/JS и Python (стандартная библиотека).

## Быстрый старт

```bash
python3 server.py
```

- Сайт: http://localhost:8000
- Админка: http://localhost:8000/admin/ (логин `admin`, пароль `admin`)

Переменные окружения:

| Переменная       | По умолчанию | Описание                          |
|------------------|--------------|-----------------------------------|
| `PORT`           | `8000`       | Порт сервера                      |
| `ADMIN_USER`     | `admin`      | Логин Basic Auth для админки/API  |
| `ADMIN_PASSWORD` | `admin`      | Пароль Basic Auth                 |

## Структура репозитория

```
├── index.html        # Сайт: hero с видео, проекты, сайты, карьера, контакты
├── content.json      # Единственный источник контента (тексты, проекты, обложки)
├── server.py         # HTTP-сервер + API админки (только stdlib Python)
├── admin/index.html  # Админ-панель в браузере
├── variants.html     # Экспериментальные варианты блока проектов
├── tailwind.css      # Стили
├── covers/           # Обложки проектов (PNG/JPG + оптимизированные WebP)
├── backups/          # Автоматические бэкапы content.json
├── portrait.mp4 / portrait-poster.webp  # Hero-видео и постер
├── trafaretkit.ttf / .woff2             # Шрифты
└── favicon*.png / apple-touch-icon.png  # Иконки
```

## Как это работает

- **Контент.** `index.html` при загрузке читает `content.json` и рендерит все секции. Ключи JSON: `page`, `hero`, `about`, `sections`, `projects`, `sites`, `companies`, `footer`.
- **Админка.** `/admin/` защищён Basic Auth. Позволяет редактировать тексты и загружать обложки проектов.
- **API** (требует авторизации):
  - `POST /admin/api/content` — сохранение `content.json` (атомарная запись + бэкап в `backups/`)
  - `POST /admin/api/upload` — загрузка файлов в `covers/` (до 50 МБ; `.png .jpg .jpeg .webp .svg .gif .mp4 .webm`)
- **Сжатие изображений.** Если установлен Pillow (`pip3 install pillow`), PNG/JPG при загрузке автоматически конвертируются в WebP (длинные скриншоты ужимаются до 1440 px по ширине). Без Pillow файлы сохраняются как есть.
- **Безопасность статики.** `server.py` и `backups/` не отдаются по HTTP; `/admin/*` и `*.json` отдаются с `Cache-Control: no-store`.

## Требования

- Python 3 (ничего дополнительно ставить не нужно)
- Опционально: Pillow — для автоконвертации загрузок в WebP

## Заметки

- Аналитика: Yandex.Metrika подключена в `index.html`.
- Для продакшена можно использовать любой статический хостинг (файлы самодостаточны), но тогда редактирование контента — через правку `content.json` в репозитории.
